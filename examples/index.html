React and Preact Transpilation

The examples on this site demonstrate React code that gets transpiled at runtime to either ES6-compatible React or Preact code using Bundless runtime builds. To use Preact instead of React, include the attribute to="preact" in the script tag. This allows you to switch between React and Preact seamlessly, depending on your requirements. No changes to your codebase are required to transition to a bundler.

Build Variants

Acorn and Meriyah have default/min and explicit prod builds without runtime inline source maps. Their .dev.js builds add runtime inline source maps so browser debugging can point back to the JSX source. Babel and Sucrase have single builds; they are not split into the same dev/prod matrix.

Runtime Builds Runtime inline source maps Notes
Acorn bundless.acorn.min.js, bundless.acorn.prod.js, bundless.acorn.dev.js Only .dev.js Acorn 36Kb. Lightweight JSX runtime.
Meriyah bundless.meriyah.min.js, bundless.meriyah.prod.js, bundless.meriyah.dev.js Only .dev.js Fast JSX parser alternative.
Babel bundless.babel.min.js Single build with Babel source maps Broad syntax support.
Sucrase bundless.sucrase.min.js Single build with Sucrase source maps Sucrase 52Kb. JSX and TypeScript transform support.
