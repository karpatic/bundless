React + JSX from static files

Build more, bundle less.

Serve App.jsx, Header.jsx, and Button.jsx as separate files. Bundless compiles the JSX in the browser and follows every local import—no bundler required.

Start with any static file server. Keep real React and a multi-file app today; add a production build when the project needs one.

Acorn is about 36.9 KiB compressed; Sucrase is about 52.5 KiB. These are the checked-in Brotli runtime files only, measured in binary KiB.
